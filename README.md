## 🔒 Summary of Privacy Principles

- **Zero Data Collection**: We do not collect, store, monitor, or track any personal identification details, contacts, locations, or usage telemetry.
- **Zero Third-Party Sharing**: No user or legal case data is ever shared with, sold to, or monetized by third-party advertisers, data brokers, or analytics platforms.
- **Client-to-Chamber Isolation**: All legal data stays strictly between the user's mobile device and their configured legal chamber backend server over encrypted TLS/HTTPS.
- **No Sensitive Device Permissions**: The app only uses standard `INTERNET` and `ACCESS_NETWORK_STATE` permissions. It does not request access to contacts, location, camera, microphone, or external files.

## 🚀 GitHub Pages Setup Instructions

To serve this repository via GitHub Pages:
1. Go to this repository on GitHub: `https://github.com/karthick-git1/neri-privacy-policy`.
2. Click **Settings** (gear icon) > **Pages** (under Code and automation in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`) / `/ (root)`
4. Click **Save**.
5. Within 1–2 minutes, your Privacy Policy will be live at:  
   **`https://karthick-git1.github.io/neri-privacy-policy/`**
6. Copy that URL and paste it into the **App Content > Privacy policy** field in **Google Play Console**.
